# pkg
Приложение для конвертации цветов между различными цветовыми пространствами.

Описание

Графическое приложение на PyQt5, позволяющее конвертировать цвета между форматами:

RGB (Red, Green, Blue) — 0-255

XYZ (CIE 1931) — 0-100

HSV (Hue, Saturation, Value) — H: 0-360°, S: 0-100%, V: 0-100%

Возможности:

Интерактивные ползунки для каждого цветового пространства

Мгновенная синхронизация всех значений

Визуальное отображение выбранного цвета

Поддержка ввода значений через spinbox

Проект разделён на независимые слои:

model.py — математика конвертации цветов

main.py — интерфейс (сгенерирован из Qt Designer)

controller.py — логика связи между интерфейсом и моделью

labacveta.py — запускает программу
